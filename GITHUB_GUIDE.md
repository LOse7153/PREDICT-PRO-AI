# Mise en ligne de PREDICT PRO AI sur GitHub

1. Ouvre https://github.com/LOse7153/PREDICT-PRO-AI dans Chrome.
2. Appuie sur **Add file** puis **Upload files**.
3. Sélectionne tous les fichiers et dossiers du projet décompressé.
4. Vérifie que `lib/main.dart`, `pubspec.yaml`, `android/` et `.github/workflows/android.yml` apparaissent à la racine.
5. En bas, choisis **Commit changes** sur `main`.
6. Ouvre ensuite **Actions** : le workflow **Build PREDICT PRO AI Android** doit démarrer.
7. Quand il est terminé avec une coche verte, ouvre le run puis **Artifacts** et télécharge `predict-pro-ai-release-apk`.

Important : le dépôt doit contenir les fichiers du projet, pas seulement le fichier ZIP. Ne mets jamais une clé football-data.org ou une clé OpenAI dans GitHub.
